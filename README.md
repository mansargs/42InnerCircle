**42 InnerCircle — Workspace Overview**

A consolidated workspace containing multiple C and C++ projects from the 42 curriculum.

**Projects**
- **CPP_Module**: C++ module exercises and examples. See [CPP_Module/README.md](CPP_Module/README.md#L1).
- **Libft**: Reimplementation of common C library functions. Build with `make` in the `Libft` directory. See [Libft/README.md](Libft/README.md#L1).
- **Get_next_line**: Line-reading utility project. See [Get_next_line/README.md](Get_next_line/README.md#L1).
- **FDF**: 3D wireframe renderer using `mlx`. Build and run with its `Makefile`. See [FDF/README.md](FDF/README.md#L1).
- **Printf**: Custom `ft_printf` implementation. See [Printf/README.md](Printf/README.md#L1).
- **Inception**: Container-oriented project with docs in `Inception/README.md`. See [Inception/README.md](Inception/README.md#L1).
- **Minitalk**: Simple IPC using signals. See [Minitalk/README.md](Minitalk/README.md#L1).
- **Push_swap**: Sorting algorithm project (mandatory + bonus). See [Push_swap/README.md](Push_swap/README.md#L1).
- **Philosophers**: Dining Philosophers concurrency project (`philo` and `philo_bonus`). Build with `make` in the `philosophers` directory. See [philosophers/README.md](philosophers/README.md#L1).
